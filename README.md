# trimslug

Trim validation gates for slug inputs before they hit prod.

**Site:** https://theworker02.github.io/trimslug/

## Install / run

```bash
git clone https://github.com/theworker02/trimslug.git
cd trimslug
node src/cli.js
node --test
```
